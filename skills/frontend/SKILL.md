# Skill de desenvolvimento Front-end

## Objetivo
Orientar o desenvolvimento da interface do jogo da forca utilizando HTML5 e CSS3, sem frameworks.

## Quando utilizar
Utilize esta Skill ao criar ou modificar a estrutura HTML, os estilos CSS, o layout ou a responsividade do projeto.

## Procedimento

1. Leia o README.md antes de iniciar o trabalho.
2. Examine os arquivos existentes antes de modificá-los.
3. Utilize HTML semântico, com elementos apropriados para cada finalidade.
4. Mantenha a estrutura HTML separada dos estilos CSS.
5. Utilize nomes de classes claros e consistentes.
6. Desenvolva um layout responsivo para celulares e computadores.
7. Garanta contraste adequado entre texto e fundo.
8. Utilize indicadores visuais claros para botões, letras selecionadas e estados do jogo.
9. Não dependa exclusivamente de cores para comunicar vitória, derrota ou erros.
10. Utilize elementos de formulário e botões acessíveis pelo teclado.
11. Evite dependências externas desnecessárias.
12. Não implemente regras de jogo no CSS nem misture estilos com a lógica JavaScript.
13. Preserve funcionalidades existentes ao modificar arquivos.
14. Ao concluir, informe os arquivos alterados e os testes realizados.

## Padrões do projeto

- HTML5, CSS3 e JavaScript puro.
- Interface em português brasileiro.
- Layout simples, moderno e consistente.
- Compatibilidade com hospedagem estática no Cloudflare Pages.
- Arquivos públicos organizados dentro da pasta public/.
- Nenhum framework sem autorização prévia.

## Critérios de conclusão

Antes de considerar a tarefa concluída, verifique:

- [ ] A estrutura HTML está organizada e sem elementos desnecessários.
- [ ] O CSS está separado e utiliza nomes de classes claros.
- [ ] A interface funciona em telas pequenas e grandes.
- [ ] Botões e elementos interativos possuem identificação acessível.
- [ ] Não foram introduzidas dependências desnecessárias.
- [ ] Os arquivos existentes e suas funcionalidades foram preservados.
- [ ] Os testes realizados e eventuais limitações foram documentados.
